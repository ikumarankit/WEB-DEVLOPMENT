BSON Data:
Binary JSON 
in mongoDb data is inserted in a special format called BSON data

advanced version of JSON
issues in JSON format solved by BSON format of data 
in JSON:
1. data is stored in text based format 
2. parsing of text based data is difficult 
3. space inefficient which is solved by bson 
4. less datatypes but in BSON there is more datatypes
we actually give JSON data to the mongodb but mongoDb internally convert this JSON format data into BSON format then store it into the memory 
so mongoDb internally use BSON format for efficient storage and data traversal





important terms:
Document and Collections:
Document: MongoDb stores data in form of documents (BSON docs)
Collection: MongoDb stores documents in collections. 
collection of documents are called collection in mongodb 

in MySQL individual data is stored in individual row/tuple 
in mongoDb individual data is stored in individual documents
{
    name: "ankit",
    age: 18,
    status: "D",
    groups: ["politics", "news"]
}

so row in MySQL === documents in MongoDb

prints all documents of the collection

for specific queries
db.collection.find({key: value})      // this query gives an array of document 
db.collection.findOne({key: value})   // this query gives one document

db.collection.find give a cursor (reference to original document) not actual document it points to the original, it is actually helpful to traverse and access individual data through loop 
where as db.collection.findOne give an actual document
we can also find document based on multiple condition {key: value, key: value}





FIND in DB
Query Operators in Find:
Find student where marks > 75
db.student.find({marks: {$gt: 75}})

Find student who live in Delhi or Mumbai 
db.student.find({city: {$in: ["Delhi", "Mumbai"]}})
values are case sensitive 

Find students who scored > 75 or live in Delhi 
db.student.find( {$or: [ {marks: {$gt: 75}}, {city: "Delhi} ]} )





UPDATE in DB
updateOne
db.collection.updateOne()   Updates at most a single document that match a specified filter even though multiple documents may match the specified filter.

db.collection.updateOne( <filter>, <update>, <options> )
db.student.updateOne( {name: "adam"}, {$set: {marks: 99}} )
here $set is update operator 

db.collection.updateMany()    Update all documents that match a specified filter 
db.student.updateMany( {city: "Delhi"}, {$set: {city:"New Delhi"}} )

db.collection.replaceOne()    Replaces at most a single document that match a specified filter even though multiple documents may match the specified filter
db.student.replaceOne({name: "bob"}, {name: "Ankit", marks: 95, city: "Delhi", state: "Bihar"})
by replaceOne we change the exisiting document value with new values 

by using replace one we can replace the existing document with new key value with same id
