Routing:
Routing means:
👉 Deciding what should happen when a user visits a specific URL (path).
/users/:id → Path
GET /users/:id → Endpoint
http://localhost:3000/users/5 → URL

Term	Meaning
URL	Full address (protocol + domain + path)
Path	Only route part (/users/5)
Endpoint	API access point (GET/POST + path)


🔹 Simple Example
When you visit:
/ → Home Page
/about → About Page
/contact → Contact Page
👉 Routing decides which code runs for each URL


We already know about the REST full APIs
how we create different different routes using REST 
Now here also we create different different routes:

now we already have 100 data in database:
now we create some routes here:
A route is a specific URL + method in your backend
app.get("/users", (req, res) => {
    res.send("Users list");
});
✔ /users = route
✔ GET = method

An API (Application Programming Interface) is a collection of routes
/users        GET
/users        POST
/users/:id    DELETE
👉 All together = Users API

Relationship:
Route = Single endpoint  
API   = Collection of endpoints
API = Restaurant 🍽️  
Route = Menu item 📋
API = full system
Route = single operation
