Installing Packages through NPM

whenever we install any npm packages then package.json and package-lock.json and node_modules folder will install generally


node_modules: The node_modules folder contains every installed dependency for your project.
package-lock.json: It records the exact version of every installed dependency, including its sub-dependencies and their versions.

require v/s import

We can't selectively load only the pieces we need with require but with import, we can selectively load only the pieces we need, which can save memory.
Loading is synchoronous for 'require' but can be asynchronus for 'import'
we have to do require or else import not both
we have to add "type": "module" in package.json file in the directory where we use import and export
