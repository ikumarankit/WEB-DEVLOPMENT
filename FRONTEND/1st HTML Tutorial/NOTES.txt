HTML LEVEL: 02
Every elements that we study in html can be classified into two categories
Inline vs Block Elements
Block Element: 
Takes up the full-width available (whole block)
starts from new line
e.g Heading, paragraph, body tag

Inline Element: Takes up only necessary width
Dont't start from new line
e.g Anchor tag, image tag

Div Element: (Content division element)
Div is a container used to hold other HTML elements or group elements together 
It is a block Element
It does not have its own functionality it is used as a container element for other elements
Websites become the collections of divs

Span Element:
Span is also a genenic container used to hold other HTML elements or group elements together
Span is an inlne element
It does not have its own functionality it is used as a container element for other elements

Semantic Markup:
It is the markup that relates to the meaning of content
Now we learn about tags whose inside content will be known by the name of the tags

Tags or elements can be classified in two categories
(i) semantic tag : we can assume what will be the content stored inside semantic tag just by seeing its name
e.g heading tag, paragraph tag, image tag, header tag, footer tag
(ii) non semantic tag : opposite of semantic tags (inka naam inke meaning ke sath itna connect nahi karta)
e.g div tag, span tag

good websites uses semantic markup
meaning se matlab hai

Why use semantic markup?
(i) meaningful / structured layout
(ii) readable
(iii) seo friendly
(iv) UX improve

Famous Tags in Semantic Markup:
<header>    topmost part of the website
<main>      middle part of the website (main content)
<footer>    last part of the website
<nav>       navigation part of the website  (direct to other webpage)

There is only one header, main and footer of the websites
more semantic tags:
<article>
<section>    to group together related content
<aside>      indirectes related links / content
