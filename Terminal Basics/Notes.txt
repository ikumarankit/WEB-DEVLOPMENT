The Terminal:
A text input and output environment 

Different Terms: 
.Command Line - any interface that is used by entering textual commands(gen. Windows centric)
.Terminal - This is a type of command line (gen. Mac centric)
.Console - A command-line interface used to work with your computer 
.Shell - A program running on terminal
.Bash - A popular shell on MacOS / Linux / Windows
.Z-Shell - Another shell (default)

Window user must install git bash to execute commands \

Basics Commands:
ls = list files (show my files)
pwd = print working directory (where am i)
clear = clear screen

Navigation:
Going Inside & Outside of the Directories 
cd = change directory
cd Desktop
cd .. = back button
we can also go two step forward and backward
cd OneDrive/Desktop
cd ../..

Paths:
Absolute & Relative 
cd OneDrive/Desktop (relative path) (starts with name of the folder)
cd /Users/kumar/OneDrive/Desktop (Absolute path) (starts with /)
/ = root directory
~ = home directory

Making Directories 
mkdir = make directory(create folders only not file)
we can create new folder using relative path as well as using absolute path 

Flags:
Flags are characters that we pass with commands to modify their behaviour 
manual Command 
man ls - give info about ls command
man mkdir - give info about mkdir command 
There is no man command in git bash 
we use commandName -h or  --h 
we use git help commandName
we use help commandName
with Flags
ls -l
ls -a 
ls -la 

Touch Command
Used to create files 
touch index.html
touch app.js
touch style.css
touch abc.txt  
Touch command real work is to change file access and modification times and if any file does exist, create 

Deleting Files & Folders 
rm - removes files
rmdir - removes empty folders 
rm-rf - remove any folders
