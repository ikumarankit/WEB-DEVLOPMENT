JSON:
JavaScript Object Notation
- a syntax
- similar to JavaScript object 
- but has less features
Difference compared to JavaScript objects:
- all property value pair are must be in double quotes in JSON
- JSON doesn't support single quotes 
- JSON doesn't support functions
why we use JSON syntax rather than JavaScript object syntax because JavaScript object only make sense in JavaScript but on the other hand JSON syntax can be understood by almost every programming languages so JSON syntax is more universal 

we use JSON:
- when we send data between two computers that might use different programming languages 
- when we store data 

so Built-in JSON object helps us: 
- convert JavaScript object => JSON
- JSON.stringify()

now let's learn how to convert back: 
- JSON => JavaScript Object
- we use another method in Built-in JSON object that is: 
- JSON.parse()

so JSON object helps us convert back and forth between JSON and JS Object 


(iv). localStorage - is another built-in object 
- localStorage object is used to save values more permanently 
- so far we've been saving our values in variables however
- variables are temporary they only exists on the current page
- if we refresh the page / close the page, all the variables are deleted
- localStorage doesn't get deleted when we refresh the page 
- method to save a value in localStorage is: localStorage.setItem()
- localStorage only support strings



More Details About Objects:
(i). null: one of the falsy value in JavaScript similar to undefined they both represent that something doesn't have a value 
Difference between null and undefined:
we use null we intensionally want something to be empty

function function1(parameter = 'default'){
    console.log(parameter);
}

function1();  // default
function1(undefined);   // default
function1(null);   // null 


(ii). Auto-Boxing: JavaScript has a special feature called Autoboxig and JavaScript automatically wraps the string in a special object this objects has properties and methods and its done automatically
- 'hello'.length
- 'hello'.toUpperCase()
Auto-Boxing also works with other types of values like numbers and booleans 
3.0.toString()
true.toString()
Autoboxing doesn't work with null and undefined
