Two more important CONSTRAINTs:
1. PRIMARY KEY: makes a column unique & not null but used only for one 
KEYS are very important when we are talking about tables 
KEY are special column 
-we can make only one column as PRIMARY KEY
-we can make PRIMARY KEY for the combination of columns but we generally make PRIMARY KEY for only one column

Two way to make any column PRIMARY KEY:
1.
CREATE TABLE user (
	id INT PRIMARY KEY,
    age INT,
    name VARCHAR(30) NOT NULL,
    email VARCHAR(50) UNIQUE,
    followers INT DEFAULT 0,
    following INT DEFAULT 0,
    CONSTRAINT CHECK (age >= 13)
);

2.
CREATE TABLE user (
	id INT,
    age INT,
    name VARCHAR(30) NOT NULL,
    email VARCHAR(50) UNIQUE,
    followers INT DEFAULT 0,
    following INT DEFAULT 0,
    CONSTRAINT CHECK (age >= 13),
    PRIMARY KEY(id)
);

KEYS in detail:
What are Keys?
Keys are special columns in the table 

Primary Key:
It is a column (or set of columns) in a table that uniquely identifies each row. (a unique id)
There is only on PK & it should be NOT null.


Foreign Key:
A Foreign key is a column (or set of columns) in a table that refers to the primary key in another table.

FKs can have duplicate & null values. but PKs never 
There can be multiple FKs.
so this how we indentify keys in our tables

Next we will learn CLAUSES in SQL:
1. Where Clause: To define some conditions 

SELECT col1, col2 FROM table_name
WHERE conditions;

there are many operators that we can use with the WHERE conditions





Operators in WHERE Clause:
Operators
Arithmetic Operators: +(addition), -, *, /, %
Comparison Operators: =, !=, >, >=, <, <=
Logical Operators: AND, OR, NOT, IN, BETWEEN, ALL, LIKE, ANY 
Bitwise Operators: &(Bitwise AND), | (Bitwise OR) it is used for bit manipulation





Frequently used operators:
AND (to check for both conditions to be true)
OR (to check for one of the conditions to be true)
BETWEEN (selects for a given range)
IN (matches any value in the list(given))
NOT (to negate the given condition)

so this is how the Logical operators works with the SQL 





2. LIMIT clause: add condition on total number of rows returned
Sets an upper limit on number of (tuples) rows to be returned 

SELECT col1, col2
FROM table_name
LIMIT number;

we can also add LIMIT clause with WHERE clause 





3. ORDER BY Clause:
To sort in ascending (ASC) or descending order (DESC)

SELECT col1, col2
FROM table_name
ORDER BY colname(s) ASC;

so with the help of this we can sort the VALUES.





Aggregate Functions:
Aggregate functions perform a calculation on a set of values, and return a single value.
.COUNT()
.MAX()
.MIN()
.SUM()
.AVG()

SELECT max(colName)
FROM table_name;

so we can write Aggregate function with the SELECT command






4. GROUP BY Clause:
Groups rows that have the same values into summary rows.
It collects data from multiple records and groups the result by one or more column.

SELECT col1, col2 
FROM table_name
GROUP BY col_name(s);

Generally we use GROUP BY with some Aggregate function.

like if we want ki user table me hamare paas 14, 15, 16, 17 age ke kitne users hai unko group karne ke lia ham GROUP BY clause ka use kar sakte hai aur fir unka count nikal sakte hai Aggregate function se 

So basically we use GROUP BY clause to Group the data and we can use Aggregate function to do some work on each group 

har age group ke hisab se kya maximum followers hai usko bhi nikal sakte hai by the help of GROUP BY and Aggregate function 






5.HAVING Clause:
Similar to WHERE i.e. applies some conditions on rows.
But it is used when we want to apply any condition after grouping 


SELECT col1, col2
FROM table_name
GROUP BY col_name(s)
HAVING condition;

WHERE is for the table, HAVING is for a group 
Grouping is necessary for HAVING 





General Order:
SELECT column(s)
FROM table_name
WHERE condition
GROUP BY column(s)
HAVING condition 
ORDER BY column(s) ASC;
