DOM (Document Object Model) 
The DOM represents a document with a logical tree.
It allows us to manipulate/change webpage content (HTML elements, CSS styling).

When we link any HTML and CSS with JS then a tree like structure will be created 
where there is multiple nodes and root node is document node and then body node and then others html elements or tags are nodes 
each node is a JS Object 

when we want to change some html elements(nodes is JS) then we can access that particular nodes and change it changes also reflect in the html 

other than window object js automatically created one more object called document object for every webpage it store all the information related to css and html
so if we change something in document object then it will also occur in html and css document

if we want to show the properties of document object then we do console.dir not console.log 
there are multiple objects also inside document object

so when we use js to change html and css then we will use this document object

There is a two step process to change html using java 
(i). select the html element/s
