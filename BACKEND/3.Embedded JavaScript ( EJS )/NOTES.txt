EJS is a simple templating language that lets you generate HTML markup with plain JavaScript.

Using EJS:
we use EJS using app.set function 
app.set("view engine" , "ejs");
here we imagine view engine as template engine and we set template engine to ejs means the thing or the packages that is used to create templates or render it is gonna be ejs

with EJS we dont send response we render it (render not send) (render means we send file )

we use res.send to send string, array, boolean, object, html as a respond
we use res.render to send files html code in the form of a file as a respond (we send .ejs file in res.render)

when we use res.render express by default go to the views folder and then check for the passed file 

jaha se server run hota hai waha se view directory ko search karta hai express

if we want ki ham agar bahar se bhi apne server ko run kare to ham res.render se ejs file ko render kar paye jo express views folder ko search kar paaye 
then we have use path package and app.set function

Serving Static Files:
till now we learn how we can render html code as a respond but in real world project of websites we also have to render css and JavaScript logic

when we send requests on websites like amazon flipkart then the respond is not only html it is css JavaScript also 

to include static files like css, js we use:
app.use(Middleware)
app.use(express.static(folder_name))  folder will contains all the static files which we can use it for html or ejs templates 
app.use(express.static(path.join(__dirname, "public")));

there should be the public named folder to serve static files like we have views folder to serve ejs files 
by default express uses public folder to access static files 

we can change the name of the public and view folder but we have to use additional function

when we run over server from parent directory then the express cannot able to find public folder so for that we use path.join method of path package 
path.join(__dirname, "public") in folder name

we can also serve two directory in path.join
path.join(__dirname, "public/js")
path.join(__dirname, "public/css")

so we can include css, and js files with ejs files
